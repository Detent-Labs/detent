- [x] 3.1 Export `buildInstanceWhere` and `buildDataWhere` from `src/runtime/api.ts` (currently module-private, at `api.ts:1304` and `api.ts:1362`). Do not update their behavior. - [x] 3.2 Implement `executeReport(reportId, actor, db)`, reusing `queryInstances`'s `InstanceQueryFilter` shape for the report's stored query. Verify with a `bun:test` that a saved report's query returns the same instances an equivalent direct `queryInstances` call would.
- [x] 3.3 Gate execution on both the report's own owner/editor/viewer membership and `can(actor, "read", processId, db)` from `src/auth/authorize.ts`. When membership passes but the process `read` check fails, return an empty table, not a refusal. Verify both `bun:test` scenarios (spec: "Report sharing narrows access, never widens it").
- [x] 3.4 Run a `DISTINCT version` query, using `buildInstanceWhere`/`buildDataWhere` from 3.1, to find the `(processId, version)` pairs the report's filter matches. For each pair, resolve its field catalog through a fresh `createDefinitionStore` (a per-execution cache, not `listInstances`'s persistent one). Union each version's catalog using `leafFields` (`src/schema/definition.ts:361`), skipping raw group containers, which carry no value. Tag the union with which versions declare each field. Verify with `bun:test`: a field only an older version declares, and a group field never offered for columns. Spec: "Column choices come from the union of field catalogs in range".
- [x] 3.5 Compute the three-way empty-cell state per direct-field column, in priority order: redacted, not-in-this-version, no-value. Redacted applies whenever the instance carries a `redactedAt` value, uniformly across every field, since `redactInstance` wipes `data` wholesale. This check does NOT gate on the field's own `redactable` flag. Not-in-this-version comes from the resolved version's catalog; no-value comes from `data[fieldId]`. Verify one `bun:test` per state, plus one confirming a `redactable: false` field still reads redacted on a redacted instance. Spec: "A cell distinguishes no-value, not-yet-existing and redacted".
- [x] 3.6 Compute a merge column's value as the first non-empty source, in declared order. When two or more sources hold a value, concatenate them and flag the row as a collision. Type and sort the result as text, and track a per-column collision count. Check `instance.redactedAt` first, the same priority 3.5's direct-field rule uses. A redacted instance's merge cell shows redacted, not as an empty value, though every source field reads empty post-redaction. Verify no-collision, collision, count, redacted (spec: "A merge column takes the first non-empty source value and marks a collision").
- [x] 3.7 Add a `truncated` flag to the execution result, mirroring `queryInstances`'s own bounding. Verify with a `bun:test` that exceeds the bound (spec: "Report execution reuses the instance-query filter axes and its bounding").
